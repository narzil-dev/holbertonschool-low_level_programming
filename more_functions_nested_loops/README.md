# C - More Functions, More Nested Loops

## Description

This project is part of the Holberton School Low-Level Programming curriculum.

It focuses on C functions, nested loops, conditional statements, variable scope, function prototypes, and header files.

## Learning Objectives

- Understand and use nested loops.
- Understand how functions work.
- Distinguish between function declarations and definitions.
- Understand function prototypes and variable scope.
- Use header files with `#include`.
- Understand the GCC flags `-Wall`, `-Werror`, `-Wextra`, `-pedantic`, and `-std=gnu89`.

## Requirements

- Ubuntu 20.04 LTS
- GCC compiler
- Betty coding style
- No global variables
- Maximum of 5 functions per file
- Function prototypes declared in `main.h`
- Use of `_putchar` for output, except where otherwise specified

## Files

| File | Description |
|---|---|
| `main.h` | Header file containing function prototypes |
| `0-isupper.c` | Checks if a character is uppercase |
| `1-isdigit.c` | Checks if a character is a digit |
| `2-mul.c` | Multiplies two integers |
| `3-print_numbers.c` | Prints digits from 0 to 9 |
| `4-print_most_numbers.c` | Prints digits from 0 to 9, excluding 2 and 4 |
| `5-more_numbers.c` | Prints numbers from 0 to 14 ten times |
| `6-print_line.c` | Draws a straight line using underscores |
| `7-print_diagonal.c` | Draws a diagonal line using backslashes |
| `8-print_square.c` | Prints a square using `#` |
| `9-fizz_buzz.c` | Prints the FizzBuzz sequence from 1 to 100 |
| `10-print_triangle.c` | Prints a right-aligned triangle using `#` |
