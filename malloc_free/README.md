# C - malloc, free

## Description

This project is part of the Holberton School low-level programming curriculum.

The goal is to learn how to use dynamic memory allocation in C with `malloc` and `free`.

## Learning Objectives

- Understand the difference between automatic and dynamic memory allocation.
- Understand when and why to use `malloc`.
- Allocate and release memory using `malloc` and `free`.
- Detect memory leaks using Valgrind.

## Files

| File | Description |
|---|---|
| `0-create_array.c` | Creates an array of characters initialized with a specific character. |
| `1-strdup.c` | Creates a dynamically allocated duplicate of a string. |
| `2-str_concat.c` | Concatenates two strings into newly allocated memory. |
| `3-alloc_grid.c` | Allocates and initializes a two-dimensional integer grid. |
| `4-free_grid.c` | Frees a previously allocated two-dimensional grid. |
| `main.h` | Contains the function prototypes. |

## Requirements

- Ubuntu 20.04 LTS
- GCC with `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style
- No global variables
- Maximum of 5 functions per file
- Only `malloc` and `free` from the C standard library
