
# C - Pointeurs de fonctions

## Description

Ce projet Holberton School permet de découvrir et de maîtriser
les pointeurs de fonctions en langage C.

## Objectifs pédagogiques

- Comprendre ce qu'est un pointeur de fonction.
- Savoir déclarer et utiliser un pointeur de fonction.
- Comprendre ce que contient un pointeur de fonction.
- Comprendre où pointe un pointeur de fonction en mémoire virtuelle.
- Apprendre à passer une fonction en paramètre.
- Utiliser des tableaux de pointeurs de fonctions.

## Contraintes techniques

- Ubuntu 20.04 LTS
- Compilateur GCC
- Standard GNU89
- Respect du style Betty
- Interdiction des variables globales
- Maximum de 5 fonctions par fichier

Options de compilation :

-Wall -Werror -Wextra -pedantic -std=gnu89

## Exercices

### 0. What's my name
Créer une fonction permettant d'afficher un nom.

### 1. Array iterator
Exécuter une fonction sur chaque élément d'un tableau.

### 2. Integer index
Rechercher un entier dans un tableau grâce à une fonction de comparaison.

### 3. Simple calculator
Créer une calculatrice utilisant des pointeurs de fonctions
et des structures.

## Fichiers

- function_pointers.h : prototypes des fonctions des exercices 0 à 2.
- 0-print_name.c : exercice 0.
- 1-array_iterator.c : exercice 1.
- 2-int_index.c : exercice 2.
- 3-calc.h : déclarations de la calculatrice.
- 3-op_functions.c : opérations arithmétiques.
- 3-get_op_func.c : sélection des opérations.
- 3-main.c : point d'entrée de la calculatrice.
