
# C - Pointers, arrays and strings

## Description

This project is part of the Holberton School low-level programming curriculum.

It focuses on pointers, arrays, strings, memory addresses, and variable scope in C.

## Learning Objectives

- Understand pointers and memory addresses.
- Use the `&` and `*` operators.
- Understand arrays and their relationship with pointers.
- Manipulate strings and the null terminator `\0`.
- Understand variable scope.

## Tasks

| File | Description |
|---|---|
| `0-reset_to_98.c` | Update an integer through a pointer |
| `1-swap.c` | Swap two integer values |
| `2-strlen.c` | Calculate the length of a string |
| `3-puts.c` | Print a string |
| `4-print_rev.c` | Print a string in reverse |
| `5-rev_string.c` | Reverse a string |
| `6-puts2.c` | Print every other character |
| `7-puts_half.c` | Print the second half of a string |
| `8-print_array.c` | Print elements of an integer array |
| `9-strcpy.c` | Copy a string |
| `100-atoi.c` | Convert a string to an integer |

## Requirements

- Ubuntu 20.04 LTS
- GCC with `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style
- No global variables
- Maximum 5 functions per file
- Standard library functions prohibited, except where explicitly allowed
