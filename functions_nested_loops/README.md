# C - Functions, nested loops

This project is part of the Holberton School curriculum.

## Description

This project introduces functions and nested loops in C programming.

## Learning Objectives

- Understand how to declare, define, and call functions.
- Understand function prototypes and variable scope.
- Use nested loops.
- Understand header files and the `#include` directive.
- Compile C programs using GCC.

## Requirements

- Ubuntu 20.04 LTS
- GCC with `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style
- No global variables
- Maximum of 5 functions per file
- No standard library functions, except where explicitly allowed
- Use `_putchar` for character output
